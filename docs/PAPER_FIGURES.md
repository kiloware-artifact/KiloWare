# Paper Figure Assets

This directory includes the final anonymous figure assets used by the current
paper draft. The figures are provided as artifact evidence and visual
provenance, not as a paper-source rebuild package.

Included final figures:

- `F0-kv-pressure-minimal`: KV-cache pressure motivation figure.
- `F1-system-overview`: KCMU system overview.
- `F2-gf-timeline`: GF owner FSM timeline.
- `F3-kiloscore`: KiloScore hardware-value scorer.
- `F32-size-sweep`: 32/32 operating-point size sweep.
- `F32-context-rates`: L1 hit and hierarchy miss by context length.
- `F32-model-l1`: model-level L1-hit breadth.

The related figure data and plotting scripts are under
`scripts/paper_figures/`.
